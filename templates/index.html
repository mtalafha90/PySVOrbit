Binary-Star Orbit Fitting

This tool works out how two stars orbit each other from your observations — and, if you provide a parallax, how much each star weighs. New to this? Start with the example file below and the glossary in step 2.

1Upload your data

Accepted formats: .inp (classic orbit-element format) or .csv/.txt (comma-separated, with an instrument/source label on each row). Your file can include astrometric (visual/interferometric) measurements, radial velocities, or both.
🎓 First time here? Download a ready-made example file — a synthetic (made-up) binary star with both astrometry and radial velocities, so you can see how the tool works before using your own data.

2Choose what to fit

Each orbital element below can be fit (checked — the tool solves for its best value) or fixed (unchecked — kept at the value from your file). Tip: if your file has no radial velocities, fix K1, K2 and V0, since there's nothing to constrain them.

What you'll get

  • The best-fit orbital elements, each with an uncertainty (± error)
  • Interactive orbit and radial-velocity plots, plus residuals (how far the fit misses each point)
  • If a parallax is given: the stars' physical masses, in solar masses
  • A downloadable results file (*_output.csv) and a PDF report
❔ What is a "fit", exactly?
The tool starts from the values in your file and adjusts the checked ("free") parameters, step by step, until the predicted orbit matches your observations as closely as possible — this is called least-squares fitting. The reported error on each parameter reflects how tightly your data pins that value down: a small error means the data strongly constrains it, a large one means it's only loosely determined (often because of too few or unevenly spaced observations).
